# Tic-tac-toe

Простая реализация классической игры "Крестики-нолики" в консольном приложении на языке C#. Игра поддерживает режим для двух игроков.

# Описание
Два игрока по очереди ставят свои символы (X и O) на поле 3x3. Цель игры - собрать три своих символа в ряд по горизонтали, вертикали или диагонали. Игра автоматически определяет победу или ничью и обрабатывает некорректный ввод пользователя.

# Функционал
* Режим 2-х игроков: Играют два человека по очереди на одном компьютере.
* Интерактивное поле: Игровое поле пронумеровано от 1 до 9 для удобства выбора ячейки.
* Автоматическая проверка: Программа сама определяет, когда игрок победил или наступила ничья.
* Обработка ошибок: Защита от ввода букв или выбора уже занятых ячеек.
* Очистка экрана: Консоль очищается перед каждым ходом для более чистого интерфейса.
